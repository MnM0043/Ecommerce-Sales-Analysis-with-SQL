# Ecommerce Sales Analysis with SQL

A portfolio project analyzing an e-commerce dataset using PostgreSQL to uncover business insights around revenue, customer behavior, product performance, and business health.

**Author:** Mohit Mohan

⬜ Milestone 5 – Portfolio Wrap-up (Pending)

## Project Objectives

- Explore and understand an unfamiliar production-style database
- Perform exploratory data analysis (EDA) using SQL
- Analyze revenue trends and business performance
- Segment customers based on purchasing behavior
- Produce business-ready insights supported by SQL queries

## Completed Work

### Milestone 2 – Get the Lay of the Land

Completed:
- Database schema exploration
- Data quality validation
- Business scale assessment
- Product catalog analysis
- Revenue contribution by category
- Business overview write-up

Key findings:
- 40,000 orders from 8,800 unique customers
- 4,000 products (3,867 active)
- Four primary product categories
- Electronics contributes over **57%** of paid revenue despite representing less than **30%** of the active product catalog
